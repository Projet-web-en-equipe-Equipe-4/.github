# Projet web en équipe - Projet Profs-pivot
## Description
Ce projet vise la refonte du site web du centre d’aide du programme d’intégration multimédia du Collège de Maisonneuve, avec un accent particulier sur le volet des profs-pivot.
[Site web du centre d'aide](https://sites.google.com/view/centre-aide-tim/accueil) 

Nous utilisons pleinement les capacités de WordPress, notamment :
- Custom Post Types (CPT)
- Advanced Custom Fields (ACF)
- Taxonomies personnalisées
- Boucles modulaires et réutilisables
Ce dépôt contient l’ensemble du code source du projet, incluant les fichiers de thème, les modèles personnalisés, les fonctions PHP, et les configurations ACF.
